About This Project

Abstract

Loan approval is an important process in banks and financial institutions. Before approving a loan, financial institutions need to analyze whether the applicant is capable of repaying the loan. This project is a Machine Learning based Loan Risk Assessment System that analyzes applicant information such as income, age, credit score, loan amount, employment type, and existing debt to classify applicants as Low Risk (no predicted default) or High Risk (predicted default).

Methodology

  1. Data Collection — A dataset of 255,347 loan applicant records (Loan_default.csv) is used.
  2. Data Preprocessing — Checking for missing values, duplicates, and encoding categorical data.
  3. Feature Selection — Choosing meaningful predictive features and excluding identifiers.
  4. Train-Test Split — 80% of data used for training, 20% for testing (stratified).
  5. Model Training — Three algorithms (Logistic Regression, Random Forest, XGBoost) are trained on the processed data and compared.
  6. Model Selection — The algorithm with the highest F1-score on the test set is automatically selected and saved for predictions.
  7. Model Evaluation — Accuracy, Precision, Recall, F1-Score, and Confusion Matrix.
  8. Risk Prediction — The trained model predicts risk for new applicants via the web app.

Technology Used

Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Joblib, Flask, HTML, CSS.
